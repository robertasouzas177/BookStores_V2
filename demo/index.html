🏛️ Pilares de Engenharia e Diferenciais da Bookstore API

🔐 Segurança & Autenticação Robusta

Tokens de acesso JWT (HS256) com tempo de vida curto (15 min) e Refresh Tokens de uso único (14 dias) com revogação automática da família inteira em caso de reuso indevido.

⚡ Cache HTTP e Concorrência Otimista

Uso rigoroso de ETag e If-None-Match com retorno 304 Not Modified para economia de banda, e If-Match com retorno 412 Precondition Failed evitando perda de atualizações.

🚨 Respostas de Erro RFC 9457

Todas as falhas retornam application/problem+json com campos canônicos: type, title, status, detail, instance, code e rastreamento X-Request-Id.

🛡️ Controle de Taxa (Token Bucket)

Rate limiting configurado em memória por IP/chave, aplicando custo diferenciado para endpoints críticos e retornando headers IETF (RateLimit-Limit, RateLimit-Remaining, RateLimit-Reset).
